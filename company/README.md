# 🏢 شركة الشخص الواحد — ٤ وكلاء Claude

نظام يشتغل داخل Claude Code: ٤ وكلاء يجهّزون الشغل، وإنت بس توافق.

## التشغيل
افتح هذا المستودع في Claude Code (الويب أو التيرمنال) واكتب:

| الأمر | شنو يسوي |
|---|---|
| `/setup` | أول مرة: يسألك ويعبّي ملفات المعرفة |
| `/morning` | فرز البريد + ردود الدعم + صفحة الصباح |
| `/content <رابط أو نص>` | فيديو واحد ← محتوى أسبوع |
| `/inbox` | فرز البريد ومسودات الردود |
| `/leads` | عملاء محتملين + فحص مواقع + إيميلات شخصية |
| `/support [سؤال]` | ردود العملاء من المعرفة |
| `/approve` | كل اللي ينتظر موافقتك |

## البنية
```
CLAUDE.md                 قواعد المنسّق (الموافقة، المعرفة، السجل)
.claude/agents/           الوكلاء الأربعة
.claude/commands/         الأوامر
.claude/settings.json     قفل الإرسال من Gmail
company/knowledge/        اللي يقرأه كل وكيل (شغلك، نبرتك، قواعدك)
company/queue/            مسودات تنتظر موافقتك
company/data/             سجل العملاء المحتملين، العملاء، الأسئلة
company/logs/run-log.md   كل إجراء يتسجّل
company/morning-page.md   صفحة الصباح
```

## المتطلبات
- Gmail و Google Calendar متصلين في Claude (Settings ← Connectors).
- النشر على المنصات يدوي حالياً: الوكيل يجهّز وإنت تنشر.

## الأمان
- الإرسال من Gmail مقفول من الإعدادات: الوكلاء يكتبون مسودات وإنت ترسل.
- لا تحط بيانات عملاء حقيقية في مستودع عام.
