# نظام إدارة الموظفين — منطقة الجهراء الصحية

نظام داخلي لإدارة شؤون الموظفين: السجلات الوظيفية، الإجازات، والحضور والانصراف.
واجهة عربية بالكامل باتجاه RTL.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 15 (App Router) |
| اللغة | TypeScript |
| التنسيق | Tailwind CSS 4 |
| قاعدة البيانات | Supabase (PostgreSQL) |
| المساعد الذكي | Claude API (`claude-opus-5`) + tool use |

## التشغيل

```bash
npm install
cp .env.example .env.local   # املأ قيم Supabase
npm run dev                  # http://localhost:3000
```

بدون ضبط متغيرات Supabase يعمل النظام على البيانات التجريبية في `lib/data.ts`.

## الصفحات

| المسار | الوصف |
|---|---|
| `/` | لوحة المؤشرات — إجمالي الموظفين، نسبة الحضور، الطلبات المعلّقة، التوزيع حسب القسم |
| `/employees` | سجل الموظفين مع مدة الخدمة ورصيد الإجازات |
| `/leaves` | طلبات الإجازات وحالاتها |
| `/attendance` | كشف الحضور والانصراف اليومي |
| `/assistant` | المساعد الذكي — استعلام بالعربية عن الموظفين والإجازات والحضور |

## المساعد الذكي

وكيل مبني على Claude مع أربع أدوات قراءة فقط على بيانات النظام:

| الأداة | الوظيفة |
|---|---|
| `search_employees` | بحث وتصفية بالاسم أو القسم أو الحالة |
| `get_employee_details` | تفاصيل موظف عبر رقم الملف |
| `list_leave_requests` | طلبات الإجازات مصفّاة بالحالة أو الموظف |
| `get_attendance_summary` | كشف حضور يوم محدد مع ملخص عددي |

الوكيل للاستعلام فقط — لا يعتمد إجازة ولا يعدّل سجلاً، وممنوع عليه
الإجابة من معرفته العامة بدون استدعاء أداة. الواجهة تعرض أسماء الأدوات
التي استُدعيت مع كل رد لتتبّع مصدر الإجابة.

يتطلب `ANTHROPIC_API_KEY`. بدونه يرجع `/api/agent` خطأ 503 وبقية الصفحات
تعمل طبيعياً.

## قاعدة البيانات

نفّذ `supabase/schema.sql` في Supabase SQL Editor. المخطط يشمل الجداول،
الفهارس، و RLS مفعّل على كل الجداول.
