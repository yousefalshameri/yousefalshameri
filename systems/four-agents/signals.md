# 01 · الإشارات

من وين تجي البيانات الخام لهالنظام. النظام مو مربوط بهالمصادر مباشرة: أنت تنزّل منها ملفات وتحطها في سجل النظام، أو تلصق المحتوى بالمحادثة.

| المصدر | شلون توصل للنظام | كل كم |
|---|---|---|
| فيديو أو فكرة | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
| البريد الوارد | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
| شركات قريبة منك | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
| سؤال عميل | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
