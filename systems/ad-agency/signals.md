# 01 · الإشارات

من وين تجي البيانات الخام لهالنظام. النظام مو مربوط بهالمصادر مباشرة: أنت تنزّل منها ملفات وتحطها في سجل النظام، أو تلصق المحتوى بالمحادثة.

| المصدر | شلون توصل للنظام | كل كم |
|---|---|---|
| تصدير حسابات الإعلانات | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
| المتجر أو الموقع | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
| التقييمات | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
| مكتبات المنافسين | تصدير يدوي إلى `records/` أو لصق بالمحادثة | أسبوعياً |
