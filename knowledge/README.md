# قاعدة المعرفة

هالملفات يقرأها كل وكيل قبل لا يكتب. عبّها مرة وحدة، وكل ما صحّحت خطأ يتكرر بمخرجات وكيل، عدّل الملف المناسب هني بدل ما تصحّح كل رد.

| الملف | شنو تحط فيه | من يقرأه |
|---|---|---|
| `voice/my-voice.md` | أسلوبك وأمثلة من كتاباتك | الكل |
| `business/offer.md` | شنو تقدّم، لمن، وبكم | العملاء، الدعم |
| `content/pillars.md` | مواضيعك ومنصاتك | المحتوى، الاستوديو |
| `leads/ideal-client.md` | مواصفات العميل المناسب | العملاء |
| `leads/log.md` | سجل المراسلات (يعبّيه الوكيل) | العملاء |
| `inbox/rules.md` | شنو مهم وشنو يُتجاهل بالبريد | البريد |
| `support/faq.md` | الأسئلة المتكررة وأجوبتها | الدعم |
| `studio/channel.md` | القناة، الجمهور، اللغات | الاستوديو |

ابدأ بـ `voice/my-voice.md`، وشغّل وكيل واحد أسبوع قبل لا تضيف الثاني.
لا تحط هني بيانات شخصية لعملاء أو كلمات سر.
