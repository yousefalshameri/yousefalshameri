# ملفات الأرقام

نزّل هني ملفات التصدير من أدواتك (CSV أو Excel)، كل نوع بمجلده:

| المجلد | شنو تحط فيه | من يقرأه |
|---|---|---|
| `ads/` | تصدير أداء الإعلانات | التسويق |
| `invoices/` | الفواتير وحالة الدفع | المالية |
| `expenses/` | المصاريف | المالية |
| `tasks/` | قائمة المهام والمواعيد | العمليات |
| `clients/` | العملاء الحاليين وآخر تواصل | نجاح العملاء |
| `reviews/` | التقييمات | الأبحاث |
| `contracts/` | العقود | الإدارة |

محتوى هالمجلد ومجلد `drafts/` ما ينرفع على GitHub (شوف `.gitignore`).
